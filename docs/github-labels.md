# GitHub Issue Labels

This document defines the recommended issue labels for the agile-final-project repository.

## Label Definitions

### 1. enhancement
- **Description**: New features or functionality requests
- **Color**: #a2eeef (light blue)
- **Usage**: Use this label for user stories and feature requests that add new capabilities to the product catalog

**Examples:**
- Adding pagination to product listings
- Implementing user authentication
- Adding product images support
- Creating an admin dashboard

---

### 2. technical debt
- **Description**: Code refactoring, optimization, or architectural improvements
- **Color**: #d4c5f9 (light purple)
- **Usage**: Use this label for tasks that improve code quality, performance, or maintainability without changing functionality

**Examples:**
- Refactoring database queries for better performance
- Adding comprehensive error handling
- Improving code documentation
- Updating dependencies to latest versions
- Converting mock implementations to real database operations

---

### 3. bug
- **Description**: Something isn't working correctly
- **Color**: #d73a4a (red)
- **Usage**: Use this label for defects, errors, or unexpected behavior in the application

**Examples:**
- Product creation endpoint returning wrong status code
- Like counter not incrementing correctly
- Search functionality returning incorrect results
- Server crashes on invalid input

---

## How to Create These Labels in GitHub

1. Navigate to your repository on GitHub
2. Click on "Issues" tab
3. Click on "Labels" button
4. Click "New label" for each label above
5. Enter the name, description, and color code
6. Click "Create label"

## Additional Recommended Labels (Optional)

- **documentation**: Improvements or additions to documentation (color: #0075ca)
- **good first issue**: Good for newcomers (color: #7057ff)
- **help wanted**: Extra attention is needed (color: #008672)
- **question**: Further information is requested (color: #d876e3)
- **wontfix**: This will not be worked on (color: #ffffff)
- **duplicate**: This issue or pull request already exists (color: #cfd3d7)
